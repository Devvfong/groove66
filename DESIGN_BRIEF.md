# Groove '66 design brief — **superseded by approved visual master**

The previous self-contained typographic-vinyl direction was an initial prototype. The user has since approved the **four-phone 1960s concept image**. That image now wins over the old layout assumptions.

**Required screenshot reference:** `docs/reference/groove66-ui-master.png`.

Important corrections compared with original prototype:
- Discover: **illustrated jukebox** hero, playlist cards and 3×2 genres, not the old vinyl poster.
- Records: **single-column protruding-vinyl cards**, not two-column grid.
- Favorites: 3-segment control, full song list, favorite-album strip.
- Navigation: fourth **Search** tab.
- Now Playing: dark wood, oversized LP, metallic knob, **tonearm**, vintage center label and **Lyrics / Queue / Devices** utility footer.

Read `docs/ux/DESIGN_SYSTEM.md` and `docs/ux/SCREEN_SPECS.md` for authoritative instructions. The existing `App.tsx` has **not** been refactored to match these requirements yet; use `CURRENT_STATE.md` and `IMPLEMENTATION_PLAN.md` to proceed truthfully.
