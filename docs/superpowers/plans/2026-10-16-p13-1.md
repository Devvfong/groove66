Goal: reproduce P13 without hand-edited generated Android or installed dependencies.
Architecture: Expo CNG; a local config plugin copies maintained Kotlin sources and registers the package. A version-pinned, fail-closed dependency patch exposes the real ExoPlayer session in playback status.

1. Preserve pristine-package comparison evidence and add regression tests that execute the production service with mocked platform boundaries (missing module, dynamic capabilities, overlapping session changes, release, persistence).
2. Copy Kotlin sources to native/equalizer, remove reflection, add native invalidation cleanup and safe numeric clamping. Add idempotent config plugin and patch installer; pin expo-audio exactly.
3. Serialize session changes, await settings hydration, consume native capabilities, detach on player disposal, and keep failures independent from playback. Keep UI frequency labels/ranges truthful.
4. Run typecheck and every scratch test. Install dependencies and generate Android in a temporary copy only; compile there if memory and toolchain permit. Use only existing emulator-5554; never start an emulator or operate on physical devices.
5. Update state, implementation plan, architecture and P13.1 report with measured evidence and explicit omissions. Do not start P14 or publish.

Review focus: missing native module must not report attached; overlapping attaches must finish on latest session; failed mutations must not claim success; hardware band differences must reach UI; release must invalidate pending attach.
